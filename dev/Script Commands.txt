Dragon Sword v2 - Script Commands
=================================

Generated from dragonsword/script_language.py, which defines the script language.
Do not rename commands or change their arguments: the game implements exactly this list.
(Help texts below are the ones shown when you right-click a cell in the Script Editor;
a "|" in a help text is a line break.)

FILE FORMAT
-----------
* Scripts are data\Scripts\<Name>.txt. File names may contain spaces, commas and brackets,
  e.g. "Chop Tree.txt", "1,1,0.txt", "Pickup [MapItem].txt".
* One command per line:  NN<TAB>Command<TAB>arg1<TAB>arg2...   (NN = 2-digit line number, 01, 02...)
* An empty argument is written as a single space so the tabs don't run together.
  Some arguments use "-" for "none" (ENTITY MISC, RACK ID for the BANK).
* Lines starting with // are comments (the editor keeps them at the top of the file).
* Commands starting with ">" are conditions. Their last argument is the line to jump to if the
  condition is NOT met; if it is met the script continues on the next line.
* GOTO LINE arguments are line numbers (NN). The editor renumbers them when lines are inserted,
  deleted or moved, and warns on save about gotos to lines that don't exist, a missing End,
  and unknown commands.
* A script ends at an End line (there can be several).
* An empty script file counts as "not found".

SCRIPT LOOKUP (from dev\Data Formats.md)
---------------------------------------
When the player does Verb on an entity/tile Name of type Type, the game runs the first that exists:
  1. "Verb Name.txt" (e.g. "Chop Tree001.txt", then without the digits, "Chop Tree.txt")
  2. "Verb [Type].txt" (e.g. "Pickup [MapItem].txt", "Drop [InventoryItem].txt")
  3. the engine's built-in default for that verb (Pickup, Drop, Examine, Eat, Talk to, Attack, Walk here)
* Using one item on another: "Use A With B.txt", then "Use B With A.txt".
* Triggers: the script name stored in the map (Trigger<TAB>ScriptName<TAB>TileX<TAB>TileY).
* Map entry: a script named after the map, e.g. "1,1,0.txt".
* Empty script files count as "not found".

    1. VIEW DISTANCE: Player's view distance through the fog (normal = 200)

End    (no arguments)
    COMMAND: Required to end the script
    (Multiple end points can exist)

Follow.Player    NPC ID | ON/OFF
    COMMAND: An NPC walks after the player, a step or two behind (ON), across maps, and waits if
    they go up a ladder, through a door or far off; OFF: it stops and stays where it is (lead someone somewhere)
    1. NPC ID: Which NPC: the Id= in its map line's Options (Map Editor: Opts, e.g. Id=OldHob),
         or CLICKED: the NPC the player clicked to start this script (talked to, attacked, used an item on)
    2. ON/OFF: ON or OFF

Get.Value    VALUE TYPE | NAME / CALCULATION | SAVE AS
    COMMAND: Retrieves a specified value and stores it in a variable
    1. VALUE TYPE: INVENTORY or BANK (how many of an item), ATTRIBUTE (a saved value), SKILL (a skill's level),
         XP (a skill's XP), HITPOINTS (current HP), EQUIPPED (the item in a slot, or none),
         or CALCULATION (a sum, or a comparison giving 1 or 0)
    2. NAME / CALCULATION: The attribute, item, skill or equipment slot to read,
         or the calculation (e.g. $Random.Percent>50 or $Variable.1+5)
    3. SAVE AS: The variable name to save the result as:
         (Variable.1$ to Variable.9$; read it later as $Variable.1 etc)

Give.Item    ITEM NAME | QUANTITY TO ADD
    COMMAND: Adds an item to the player's inventory
    1. ITEM NAME: The name of the item (from sprites\Entities, e.g. Gold_Coin(s))
    2. QUANTITY TO ADD: The quantity of the item to add

Goto.Line    GOTO LINE
    COMMAND: Continues the script on a specified line
    1. GOTO LINE: The line number to continue at

Goto.Script    GOTO SCRIPT NAME
    COMMAND: Runs a new script
    1. GOTO SCRIPT NAME: The name of the script to run:
         (Located in the 'data\Scripts\' folder)

Move.Entity    X COORDINATE,Y COORDINATE | ENTITY NAME | TARGET X,TARGET Y | SPEED
    COMMAND: Moves an Entity from its current position to the target position
    (An NPC walks back to its zone or patrol afterwards, like after a chase)
    1. X COORDINATE,Y COORDINATE: The X and Y coordinates, separated by a comma (e.g. 300,250 or $Player.X,$Player.Y).
         In PIXELS, except for Change.Tile and >Tile.In.Line.Of.Sight, which take TILE coordinates (1-25,1-21)
    2. ENTITY NAME: The name of the entity (from sprites\Entities)
    3. TARGET X,TARGET Y: The point to move to, in PIXELS (TargetX,TargetY), e.g. $Player.X,$Player.Y
    4. SPEED: The speed at which to move (1 = slow, 5 = fast)

Move.Player    TARGET X,TARGET Y | SPEED
    COMMAND: Moves the Player from their current position to the target position
    1. TARGET X,TARGET Y: The point to move to, in PIXELS (TargetX,TargetY), e.g. $Player.X,$Player.Y
    2. SPEED: The speed at which to move (1 = slow, 5 = fast)

Play.Animation    ANIMATION | TIMES | SOUND
    COMMAND: The work of the hands: an animation on what the player clicked, a lunge towards it
    and a sound, TIMES over (a beat every 0.8 seconds), e.g. Wood_Chips 3 WoodChop for three swings of the axe
    1. ANIMATION: An animation from sprites\Effects (<Name>1..4): Wood_Chips, Rock_Chips, Splash, Dirt_Clods,
         Wool_Tufts, Slash, Puff, Fire_Burst...
    2. TIMES: How many beats (1-8): one each 0.8 seconds
    3. SOUND: A sound from the '\sounds\' folder to play with it, e.g. Denied (a no), Empty, Quest
         (Display.Refusal: Denied if none is given; Display.Message, Play.Animation: none)

Play.Minigame    MINIGAME | LEVEL | GOTO LINE IF LOST
    COMMAND: A minigame on the game screen; the script waits for it. Won: on to the next line;
    lost (or walked away from): on at the line given
    1. MINIGAME: Which: LOCK (picking a lock: set each pin as it crosses the line; three slips and it's lost)
    2. LEVEL: How hard, 1 to 5 (a lock: 1 is three pins, wide; each level a pin more, and narrower)
    3. GOTO LINE IF LOST: The line that the script continues at if the minigame is lost or left

Play.Sound    SOUND FILE
    COMMAND: Plays a sound file stored in the '\sounds\' folder
    1. SOUND FILE: A sound from the '\sounds\' folder (.wav, or .mid which briefly replaces the music).
         Without an extension the game looks for a .wav, then a .mid

Quest.Note    QUEST NAME | NOTE
    COMMAND: Writes a line in a quest's notes in the journal
    (the checklist shown when you point at the quest; the same line again changes nothing)
    1. QUEST NAME: The quest: its title in data\Quests.ini, or its Attribute
         (e.g. The Withering Wood or DruidQuest)
    2. NOTE: The line in the quest's notes, e.g. what to do next or a clue
         (Quest.Note.Done: the line to cross out; * crosses out all of them)

Quest.Note.Done    QUEST NAME | NOTE
    COMMAND: Crosses out a line in a quest's notes in the journal
    (it is added crossed out if it isn't there yet)
    1. QUEST NAME: The quest: its title in data\Quests.ini, or its Attribute
         (e.g. The Withering Wood or DruidQuest)
    2. NOTE: The line in the quest's notes, e.g. what to do next or a clue
         (Quest.Note.Done: the line to cross out; * crosses out all of them)

Remove.Action.From.Queue    QUEUE ENTRY
    COMMAND: Removes entries from the spawning queue
    (e.g. to cancel something added by Add.Action.To.Queue)
    1. QUEUE ENTRY: The queue entry to remove: the Add.Action.To.Queue arguments joined with [TAB]

         Use * at the end to match the rest of the entry

    1. NPC ID: Which NPC: the Id= in its map line's Options (Map Editor: Opts, e.g. Id=OldHob),

Set.NPC.State    NPC ID | STATE
    COMMAND: The NPC rests in a pose of its kind from now on (and stays put while it's sitting);
    - or nothing: it stands, and rests as its kind does again (for everyone: it's the world's NPC)
    1. NPC ID: Which NPC: the Id= in its map line's Options (Map Editor: Opts, e.g. Id=OldHob),
         or CLICKED: the NPC the player clicked to start this script (talked to, attacked, used an item on)
    2. STATE: A pose of its kind (Entities.ini States= or Fidgets=, e.g. Sit), or - to let it be

Turn.Into    FORM | SECONDS | MESSAGE
    COMMAND: The player becomes a creature for a while (its walking frames: Chicken, Cat...), then snaps back
    (no hands meanwhile; monsters pay them no mind; $Player.Form is what they are)
    1. FORM: What they become: a creature with walking frames (Chicken, Cat, Duck...)
    2. SECONDS: For how many seconds
    3. MESSAGE: The message that is displayed in the chat box. One that starts .. finishes the line before it
         (if that ended ..): "You swing your axe.." then "..and get some logs!" make one line, in the colour of the second
