Each was made mono 22050 Hz and its loudness matched to the game's own sounds. The greetings, growls, quest
jingles and animals' noises are cut from the recordings by `dev/migrate/build_voices.py`, which fetches them the first time.

The music of the towns, the Isle, the open road and the fights is royalty-free music licensed for the game:

| File | Where it plays |
|---|---|
| `sounds/music/isle.mp3` | the Isle |
| `sounds/music/northport.mp3` | Northport |
| `sounds/music/galaith.mp3` | Galaith |
| `sounds/music/emberwatch.mp3` | Emberwatch |
| `sounds/music/rupertskeep.mp3` | King Rupert's Keep |
| `sounds/music/sandtown.mp3` | Dunerest, the desert's town |
| `sounds/music/town.mp3` | the other towns |
| `sounds/music/exploration.mp3`, `exploration2.mp3` | outside the towns, in turn |
| `sounds/music/combat.mp3` | fighting a foe |

Each was made mono at 64 kbit/s, at most three minutes long and to one loudness by `dev/migrate/shrink_music.py`
(the tracks as they came are kept out of the repository, in `dev/Music`).

The server and the Android app run on open-source software: Python (PSF licence), aiohttp (Apache 2.0) and
Chaquopy (MIT).
